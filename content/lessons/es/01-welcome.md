Te damos la bienvenida a **Gentle Shell School**, un curso gratuito y a tu propio
ritmo para aprender gentle-shell: el entorno para agentes de programación basado en Pi.

## Cómo funciona este curso

Cada lección tiene dos audiencias:

- **Tú** lees la lección aquí, en el sitio web.
- **Tu agente** lee la misma lección a través de la API del curso. Cada lección
  incluye instrucciones que le indican al agente cómo es el resultado esperado y cómo
  verificarlo.

Cualquier agente de programación puede iniciar el curso. Explica cada tema, hace
preguntas de cuestionario cuando corresponde y verifica tu configuración real antes de
marcar una lección como completada. Si ese primer agente no es gentle-shell, las dos
siguientes lecciones te ayudan a instalar y abrir Gentle Shell, y luego transfieren el
progreso de tu curso a su agente.

¿Ya usas gentle-shell? Instala el paquete del tutor del curso, reinicia Pi y luego
usa `/school` para comenzar o continuar el curso:

```sh
pi install git:github.com/iachettifederico/gentle-shell-school
```

¿Encontraste un problema? Tu agente puede reportarlo como un issue de GitHub con tu
consentimiento, o puedes usar el enlace "Reportar un problema".

## Inicia el curso

Pídele a cualquier agente de programación:

```text
Read {origin}/llms.txt and start the course.
```
