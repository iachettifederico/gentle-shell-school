# Abre Gentle Shell

Has confirmado que el iniciador `gentle-shell` está disponible. Ahora inícialo y pega
tu primer prompt de lección. A partir de aquí, todas las lecciones funcionan de la
misma manera.

## Inicia el espacio de trabajo

En una terminal, ejecuta:

```bash
gentle-shell
```

Esto abre Pi con el paquete de Gentle Shell cargado. El iniciador normalmente usa su
propio home de agente aislado, por lo que puede configurar su espacio de trabajo sin
editar un agente Pi existente. Espera hasta que la sesión interactiva esté lista.

## Pega tu primer prompt

¿Todavía no te inscribiste? Inscríbete con el botón de la página de inicio y luego
regresa aquí: el prompt aparecerá en la parte superior de esta página, con tu ID
anónimo de estudiante.

Copia el prompt en la parte superior de esta página y pégalo en Gentle Shell. Tu agente
lee las instrucciones del curso en tu idioma, confirma que Gentle Shell funciona,
registra las primeras tres lecciones y te da el prompt para **Las capas de Gentle Shell**.

## El ciclo desde aquí

Cada página de lección tiene su prompt en la parte superior. Pégalo, aprende con tu
agente y, al final, te entrega el siguiente prompt. Mantén esta página abierta: cuando
tu agente registra una lección, la página la muestra sin recargar y enlaza a la siguiente.

Si el comando no inicia Gentle Shell, vuelve a **Instala Gentle Shell** y repite su
verificación de versión.
