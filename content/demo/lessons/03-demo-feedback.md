# Practice reporting problems safely

Good feedback helps keep a course accurate, but reporting is always your
choice. Agents follow the **Reporting problems** guidance in `/llms.txt`: they
explain what would be shared, ask for explicit consent, and avoid private
information. They should never file something just because a lesson was
confusing.

For this local demo course, practice only the consent step. Ask your agent to
walk through the reporting flow for an imaginary typo. When it offers the
choices, select **Continue without reporting**. That is a valid outcome: you
have reviewed the option and decided not to send anything.

No GitHub issue, message, or other report should be created during this
exercise. The purpose is to make the consent boundary visible before you ever
need to use it for a real problem. You can return to the full course whenever
you are ready to learn the complete feedback workflow.

This remains a **local demo course** and nothing is filed.
