# Practica informar problemas de forma segura

Los buenos comentarios ayudan a mantener preciso un curso, pero informar siempre
es tu decisión. Los agentes siguen la guía de **Reporting problems** en
`/llms.txt`: explican qué se compartiría, piden consentimiento explícito y evitan
la información privada. Nunca deben enviar algo solo porque una lección fue
confusa.

Para este curso demo local, practica solo el paso de consentimiento. Pídele a tu
agente que recorra el flujo de reporte para un error tipográfico imaginario.
Cuando ofrezca las opciones, selecciona **Continue without reporting**. Ese es
un resultado válido: revisaste la opción y decidiste no enviar nada.

No se debe crear ningún issue de GitHub, mensaje u otro reporte durante este
ejercicio. El propósito es hacer visible el límite del consentimiento antes de
que necesites usarlo para un problema real. Puedes volver al curso completo
cuando estés listo para aprender el flujo completo de comentarios.

Este sigue siendo un **curso demo local** y no se envía nada.
