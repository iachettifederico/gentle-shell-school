# Bienvenida al curso demo local

Este curso pequeño te permite probar Gentle Shell School sin recorrer todo el
plan de estudios. Se ejecuta únicamente en tu servidor de desarrollo local, así
que es un lugar útil para ver cómo encajan el sitio web, la API de lecciones y
las instrucciones del agente.

Cada lección tiene dos lectores. Tú lees la página en el navegador. Tu agente
puede leer la misma lección mediante la API y usar sus instrucciones para
guiarte. Eso convierte al agente en un tutor: puede explicar el material,
hacer una pregunta de cuestionario cuando una lección tiene una y confirmar una
verificación de configuración real antes de que avances.

En este demo, nada cambia la instalación ni los archivos de tu curso. Lee una
lección, conversa sobre ella con tu agente y elige cuándo continuar. La siguiente
lección incluye un cuestionario breve y una verificación de comando inofensiva.
La última lección practica el paso de consentimiento para informar un problema
sin enviar nada.

Este es un **curso demo local**, no el plan de estudios completo de Gentle Shell
School.
