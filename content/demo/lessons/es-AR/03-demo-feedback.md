# Practicá informar problemas de forma segura

Los buenos comentarios ayudan a mantener un curso preciso, pero informar siempre
es tu elección. Los agentes siguen la guía **Reporting problems** de `/llms.txt`: te
explican qué se compartiría, piden consentimiento explícito y evitan la
información privada. Nunca deberían enviar algo solo porque una lección resultó
confusa.

Para este curso de demostración local, practicá únicamente el paso de
consentimiento. Pedile a tu agente que recorra el flujo de reporte por un error
tipográfico imaginario. Cuando ofrezca las opciones, elegí **Continue without reporting**.
Ese es un resultado válido: revisaste la opción y decidiste no enviar nada.

No se debería crear ningún issue de GitHub, mensaje ni otro reporte durante este
ejercicio. El propósito es hacer visible el límite del consentimiento antes de que
necesites usarlo para un problema real. Podés volver al curso completo cuando
estés listo para aprender el flujo íntegro de comentarios.

Este sigue siendo un **curso de demostración local** y no se envía nada.
