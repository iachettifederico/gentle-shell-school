# Bienvenida al curso de demostración local

Este curso breve te permite probar Gentle Shell School sin recorrer el
programa completo. Se ejecuta solamente en tu servidor de desarrollo local, por
lo que es un lugar útil para ver cómo encajan el sitio web, la API de lecciones y
las instrucciones del agente.

Cada lección tiene dos lectores. Vos leés la página en tu navegador. Tu agente
puede leer la misma lección mediante la API y usar sus instrucciones para guiarte.
Eso hace que el agente sea un tutor: puede explicar el material, hacerte una
pregunta de cuestionario cuando una lección tiene una y confirmar una comprobación
real de configuración antes de que sigas avanzando.

En esta demo, nada cambia la instalación ni los archivos de tu curso. Leé una
lección, conversala con tu agente y elegí cuándo continuar. La siguiente lección
incluye un cuestionario breve y una comprobación de comando inocua. La última
lección practica el paso de consentimiento para informar un problema sin enviar
nada.

Este es un **curso de demostración local**, no el programa completo de Gentle Shell School.
